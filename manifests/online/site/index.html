How this page got here

  1. BriefSquad plans the change; one lane owns each file.
  2. CodeCopilot CLI writes Terraform against a reusable AzAPI module.
  3. Checkfmt, validate, offline tests, TFLint, Trivy, Checkov, CodeQL.
  4. PlanA pull request, then a plan a human reads.
  5. ApproveThe environment gate needs a reviewer. No apply from a laptop.
  6. ProveOIDC deploy from an ephemeral runner, then an HTTPS check by hostname.

What is underneath

Cluster

  • AKS Automatic SKU, managed system node pools
  • Entra ID + Azure RBAC only, local accounts off
  • Azure Policy and Key Vault secrets provider add-ons
  • Node resource group locked to read-only

Network

  • Own VNet, an NSG on every subnet
  • Egress through a NAT Gateway with a static IP
  • API server reachable only from the runner's IP
  • Managed NGINX ingress (App Routing), HTTP forced to HTTPS

This workload

  • Non-root, read-only root filesystem
  • All Linux capabilities dropped, seccomp on
  • Default-deny network policy, ingress only from NGINX
  • Image pinned by digest, Pod Security "restricted"

Your browser warned you about the certificate. That's deliberate: the demo uses the ingress default self-signed certificate. In production, put a CA-issued certificate in Key Vault and let the App Routing add-on serve it.
